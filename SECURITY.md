# Security Policy

## Supported Versions

Currently, this project is in its initial development phase. Security updates will be provided for the latest released version.

## Reporting Security Vulnerabilities

We take the security of this project seriously. If you discover a security vulnerability, please help us by reporting it responsibly.

### How to Report

1. **Do not** open a public issue on GitHub
2. Email your report to: security@ai-agent-skills.local
3. Include in your report:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

## Scope

This project contains educational content for AI agents. While we strive to ensure all content is accurate and safe, users should:

- Review code examples before using them in production
- Validate all inputs and outputs in their specific use cases
- Follow security best practices in their implementations
